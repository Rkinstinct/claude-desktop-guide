# Remotion source - סרטוני המדריך

קוד המקור (Remotion / React) של כל הסרטונים המונפשים באתר: כרטיסי הפרקים, סרטוני ההסבר של המנגנונים, סרטוני ה"מה למדנו", חגיגות החידון וסיום המדריך, לולאת התצוגה המקדימה בעמוד הבית וקליפ השיתוף.

קבצי הווידאו עצמם (mp4) לא נמצאים כאן - הם נשמרים כ-assets ב-release `videos-v1`.

## רינדור

```
npm install
npx remotion render src/index.ts <CompositionId> out/<name>.mp4 --codec=h264 --crf=18
```

פרמטרים לסרטוני ה"מה למדנו" (Recap) עוברים עם `--props=<json>` בשלוש שורות לכל פרק.

כל הקומפוזיציות: 1080x608 (חוץ מ-ShareClip שהוא 1080x1920), 30fps, פונט Heebo, RTL.
